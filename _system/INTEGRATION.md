# Knowledge Integration

役割分担:

Windows / Smartphone
  -> Obsidian
     -> Hearth: Dashboard / Home
     -> Bases: 標準の一覧・絞り込み
     -> Dataview: 複雑な抽出
     -> Single HTML Export: 共有用HTML
     -> Obsidian Sync: PC <-> Smartphone
  -> Markdown + assets
  <- Kaku: AI / Agent編集
  <- Future Jev / Scanner: Properties更新
  -> GitHub: 履歴・バックアップ・Agent操作

原則:
- Markdown + assets がSSOT。
- Kaku用にMarkdownを複製しない。
- JevはHearthのレイアウトを直接操作しない。
- Jev/Scannerは _system/KNOWLEDGE_SCHEMA.md のPropertiesだけ更新する。
- DashboardはPropertiesを読む。
- HTMLは共有成果物でありSSOTにはしない。
