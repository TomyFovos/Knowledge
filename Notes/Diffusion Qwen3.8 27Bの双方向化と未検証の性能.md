# Diffusion Qwen3.8 27Bの双方向化と未検証の性能

Diffusion-Qwen3.8-27Bは、提供資料によれば、自己回帰モデルQwen3.8-27Bをマスク拡散型へ作り替えた研究用チェックポイントである。注意機構に加え、Gated DeltaNetの層にも逆方向の流れを足した点が紹介されている。

この記録は2026-11-19の提供資料に基づく。中心の公開投稿は会話に貼られた本文で、URLは元資料でも未確認。今回の取り込みでは配布物・論文・モデル構成を再確認しておらず、モデルの取得や評価も行っていない。

## 注意機構とGated DeltaNet

資料は、元モデルを64層の混成構造として説明する。その内訳は16層の注意機構と48層のGated DeltaNetで、3つのDeltaNet層と1つの注意層を繰り返す構成と記されている。

| 層 | 元資料が説明する一方向の仕組み | 資料中の変更 |
|---|---|---|
| 注意機構 | 因果マスクで未来の位置を参照しない | 因果マスクを外し、前後の位置を参照できるようにする |
| Gated DeltaNet | 前から状態を更新し、情報を受け渡す | 逆方向の流れを足し、各位置で前後の情報をゲートで混ぜる |

DeltaNetを「前から順に読む」と表すのは、位置間の状態依存を説明する比喩であり、実際のハードウェア実装が必ず逐次処理になるという意味ではない。前向きと後ろ向きの流れは独立に計算できる構成として資料が紹介している。

```text
前向き： A → B → C → D
逆向き： A ← B ← C ← D
                      ↓
           各位置で両方向をゲートで混合
```

資料は、先行例dQwen3.5では注意層を双方向にし、Gated DeltaNetは前向きのまま残したと説明する。これは当該比較の設計差であり、拡散生成には必ず全層の双方向化が必要という意味ではない。

## 何を生成し、どんな誤りが残るか

投稿の説明では、質問を固定し、回答部分のマスクを各回で予測して、信頼度の高い位置を確定する。確定した語は後から直さないため、早い段階で誤った内容を確定すると、その内容を前提に残りが自然につながる可能性がある。

しきい値を下げて一度に多く確定させる案には、反復の削減と誤確定の増加の両面がある。ただし、発生頻度や最適なしきい値は資料にない。

## 新しい構成と性能結果を分ける

元資料では、公開投稿の時点で元のモデルとの精度・速度比較はまだない。逆方向の流れが品質を改善するか、追加計算に見合うかは未検証である。

「DeltaNetの計算がおよそ倍」「反復を減らさないと元モデルより遅い可能性」は会話中の推測として記録されている。前向き・逆向きの2経路があることから、実際のレイテンシや総費用をそのまま2倍と決めることはできない。

別資料の重み空間プログラミングにもQwen3.8-27Bが登場するが、こちらは生成方式の変更を扱う。重み編集の研究や同名の別チェックポイントと同一視しない。
