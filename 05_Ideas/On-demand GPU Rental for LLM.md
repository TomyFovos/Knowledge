# On-demand GPU Rental for LLM

Status: Idea

## アイデア

GPU貸出サービスを使い、LLMを必要なタイミングだけ起動する。

常時GPUマシンを保有・稼働させるのではなく、生成や検証を行いたいときだけ時間貸しのGPU環境を立ち上げる運用を想定する。

## 背景

ローカルで動かしたいLLMでも、必要なGPU性能を常に手元へ用意するのはコストが高い。元メモでは、時間貸しGPUなら必要なときだけ開始できる点を利点として記録していた。

## 期待する効果

- 高性能GPUを常設せずにLLMを試せる
- 利用しない時間のGPUコストを抑えられる可能性がある
- 手元のGPUでは動かしにくいモデルの検証候補になる

## 課題

- 起動・停止を忘れた場合の課金管理
- モデルやデータを外部環境へ置く場合のセキュリティ
- モデル取得や環境構築にかかる起動時間
- 常時運用と時間貸しのどちらが安いかは利用頻度次第

## 次に試すこと

実際に使いたいモデルを1つ決め、必要GPU・1回あたりの利用時間・月間利用頻度を基に、手元GPUや常設サーバーとコスト比較する。
